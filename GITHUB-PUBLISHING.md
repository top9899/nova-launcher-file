# GitHub publication notes

This folder contains the NOVA Launcher source and build metadata. It intentionally excludes compiled installers, `node_modules`, local caches, user profiles, Minecraft files, and AI key storage.

Before publishing, review the repository contents and commit history for credentials. Never commit Google OAuth client secrets, Firebase service-account files, API keys, or user data. The AI provider keys entered in NOVA are stored under the current user's application data folder and are not part of this source package.
