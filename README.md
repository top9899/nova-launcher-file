# NOVA Launcher

Минималистичный лаунчер Minecraft Java Edition на Electron. Получает официальные релизы и снапшоты из каталога Mojang, сохраняет никнейм локально, скачивает выбранную версию и запускает её через Minecraft Launcher Core.

## Запуск

1. Установите Node.js 20 или новее и Java, подходящую для выбранной версии Minecraft.
2. В папке проекта выполните `npm install`.
3. Выполните `npm start`.

Чтобы собрать установщик Windows x64 (`.exe`), выполните `npm run dist`. Распакованную сборку для быстрой проверки можно получить командой `npm run pack`.

Игровые файлы хранятся в `%APPDATA%\NOVA Launcher\minecraft`.

Лаунчер проверяет наличие Java и сверяет её версию с требованиями выбранной версии Minecraft. Он не устанавливает Java автоматически.

## Версии, загрузчики и моды

- В библиотеке версий можно включать и выключать снапшоты и старые альфа-/бета-версии.
- Для профиля Minecraft доступны Vanilla, Fabric и Forge. Профили и папки `mods` изолированы по версии игры и загрузчику.
- Каталог Modrinth встроен в лаунчер: поиск учитывает версию Minecraft и загрузчик, а установка проверяет контрольные суммы и добавляет обязательные зависимости.
- CurseForge открывается в браузере; скачанный `.jar` можно импортировать кнопкой в разделе модов. Прямая интеграция с CurseForge API требует ключа платформы.
- При первом запуске Fabric-профиля лаунчер автоматически добавляет совместимый Fabric API.
- В библиотеке версий кнопка «＋ Fabric» устанавливает Fabric и совместимый Fabric API для выбранной версии Minecraft; установленный профиль отмечается в списке.
- Раздел «Разработка» создаёт Fabric-проект с Gradle Wrapper, простым редактором, сборкой JAR и запуском тестового клиента. Готовый JAR можно поставить в игровой профиль или открыть папку проекта.
- В проекте отображается дерево папок и файлов, включая `src/main/java`, `src/main/resources`, Gradle и бинарные ресурсы; путь проекта показан полностью. Текстовые файлы редактируются внутри, бинарные можно быстро найти в Проводнике.
- В панели AI можно подключить OpenAI, Gemini или Claude. API-ключи шифруются средствами Windows; расходы и лимиты определяются выбранным провайдером.
- В режиме разработки можно проверить подключение к API, получить доступные модели, вести диалог с контекстом открытого файла и удалить ключ провайдера. Проекты можно переместить в Корзину Windows после подтверждения.

## Аккаунт

Сейчас реализован офлайн-профиль. Никнейм работает для одиночной игры и серверов, разрешающих офлайн-подключения. Для серверов с проверкой аккаунта и онлайн-профилей Microsoft понадобится настроить OAuth/Xbox/Minecraft authentication; эта версия не запрашивает и не хранит пароль или токены Microsoft.

## Компоненты

- Electron — окно приложения.
- Minecraft Launcher Core — загрузка и запуск официальных игровых файлов.
- Каталог версий: `https://launchermeta.mojang.com/mc/game/version_manifest.json`.
